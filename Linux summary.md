. Internet Infrastructure and Servers 
Internet Connectivity: Data moves globally through underwater fiber optic cables connecting data centers, rather than relying solely on satellite communication.
Servers: Specialized computers designed to "serve" information. Types include:
Email Server: Manages email exchange.
File Server: Stores and retrieves files.
Database Server: Manages data insertion and queries.
Application Server: Runs business logic (e.g., Django, Node.js).
Web Server: Serves static content like images and HTML (e.g., Nginx).
Client-Server Model: The client (browser/phone) sends a request, and the server provides the requested information.
II. Linux OS and Server Setup 
Linux OS: An open-source operating system providing the core environment for most servers.
Server Setup: Involves choosing a distribution (like Ubuntu) and deploying it via cloud platforms (like AWS).
III. Linux Commands for DevOps
Basic Commands:
ls: List directory contents.
mkdir: Create a directory.
rm: Remove files (use rm -rf for recursive directory removal).
touch: Create empty files.
cat: View file content.
head/tail: View the beginning or end of files.
cp: Copy files/folders.
mv: Move or rename files/folders.
wc: Word count (lines, words, bytes).
IV. Advanced Linux Management 
Links: ln creates hard links; ln -s creates soft (symbolic) links.
User Management: useradd, usermod, userdel are used for account administration. Groups are created using groupadd to manage permissions for multiple users efficiently.
File Permissions: Use chmod to change read/write/execute access and chown to change file ownership.
UMASK: Defines default permissions for newly created files.
