# Git aur GitHub — Complete Notes

## 1. Git aur GitHub ka Ta'aruf (0:00 – 5:00)<br>

**Git:** Yeh ek Version Control System hai jo code ki history track karta hai aur team collaboration mein madad deta hai.<br>

**GitHub:** Yeh ek online platform hai jahan aap apna code store aur manage kar sakte hain.<br><br>

## 2. Setup aur Installation (16:45 – 20:30)<br>

**VS Code:** Coding ke liye istemal hone wala software.<br>

**Git Configuration:** Apna naam aur email set karne ke liye:<br>

```bash
git config --global user.name "Name"
git config --global user.email "your@email.com"
```

<br>

---

## 3. Zaroori Git Commands (25:23 – 40:00)<br>

**git clone:** Kisi repository ko apne computer par lana.<br><br>

**git init:** Ek folder ko Git repository mein badalna.<br><br>

**git status:** Files ka current status check karna — Modified, Staged, ya Untracked.<br><br>

**git add:** Changes ko Staging Area mein daalna.<br><br>

**git commit:** Changes ka snapshot save karna.<br><br>

**git push:** Apne local commits ko GitHub par upload karna.<br><br>

---

## 4. Branching aur Collaboration (44:41 – 55:20)<br>

**Branch:** Main code se alag branch bana kar us par kaam karna.<br><br>

**git branch:** Branches check karna.<br><br>

**git checkout:** Ek branch se doosri branch par jana.<br><br>

**Merge:** Do branches ke changes ko combine karna.<br><br>

---

## 5. Merge Conflicts aur Reset (1:02:43 – 1:11:00)<br>

**Merge Conflict:** Jab do branches mein same line par different changes hon, toh conflict aa sakta hai. Isay manually resolve karna parta hai.<br><br>

**git reset:** Commits ko undo karne ke liye istemal hota hai.<br><br>

**git reset --hard:** Current branch ke changes aur commit position ko reset karta hai. Is se uncommitted changes delete ho sakte hain.<br><br>

---

## 6. Forking (1:12:03 – 1:12:50)<br>

**Fork:** Kisi aur ke project ki copy apne GitHub account mein banana, taake aap us project mein apni changes kar sakein aur contribute kar sakein.<b
